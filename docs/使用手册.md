> [历史-Rust方案](历史-Rust方案.md) 是初版技术选型（Rust，已作废），

## 一、这是什么

一个 Windows 上刷抖音的桌面程序。

它**不打开抖音网页**，而是直接走接口拿视频、用 mpv 播放。所以：

- 没有网页加载的等待，切换视频通常在 100 毫秒以内
- 没有广告、没有推荐位、没有埋点
- 内存占用约 400 MB（主程序 + 播放器）

支持：推荐流、扫码登录、评论区、图集作品、全屏、键盘快捷键。

## 二、第一次运行

### 前置条件

**安装版（从 Releases 下载的）**：什么都不用装，`DouyinDesktop.exe` 自带 .NET 运行时。
唯一要确认的是播放器在不在：

| 需要什么 | 怎么确认 | 没有怎么办 |
| --- | --- | --- |
| mpv 播放器 | `assets\mpv\mpv.exe` 存在 | 下载 `mpv-win64.zip` 解压进来，或跑 `scripts\fetch-mpv.ps1` |

**从源码运行**：额外需要 .NET 10 SDK，`scripts\env.ps1` 会检查，缺了跑 `scripts\setup.ps1`。

### 启动

安装版：双击 `DouyinDesktop.exe`。

从源码跑，在项目根目录打开 **PowerShell**：

```powershell
. .\scripts\env.ps1
cd src
dotnet run --project DouyinDesktop.App
```

> 前面那个点号不能少。它表示"在当前窗口执行"，少了它环境变量不会留下。

## 三、怎么用

### 键盘

| 按键 | 作用 |
| --- | --- |
| `↑` / `W` | 上一条 |
| `↓` / `S` | 下一条 |
| `←` / `A` | 快退 5 秒（图集时：上一张） |
| `→` / `D` | 快进 5 秒（图集时：下一张） |
| `空格` | 暂停 / 继续 |
| `M` | 静音 |
| `F` | 全屏（`Esc` 退出） |
| `Tab` | 循环切换「详情 → 评论 → 主页 → 详情」 |
| `G` | 切换「关注 / 推荐」 |
| `U` | 看当前作者主页 / 回推荐 |
| `X` | 点赞 / 取消点赞（需登录） |
| `B` | 在浏览器中打开当前作品 |
| `Esc` | 退一层：全屏→退全屏；作者主页→回推荐 |
| `Ctrl+O` | 打开设置 |

**快捷键可以改**：按 `Ctrl+O` 或点标题栏「设置」，在列表里点「修改」再按新键即可。
方向键和 WASD 是固定别名，不受影响。

**换一批、登录默认不绑键**——都不是高频操作，绑着反而容易误触。
换一批翻到快见底会自动补；登录在设置 → 账号里有入口。要用的自己去设置里加。

`U`（作者主页）从 1.2.0 起默认绑上了：喜欢/收藏页的「主页」显示的是封面墙，
想看当前作者的作品只剩这一条路。

详情页只列不常用的键，`↑↓←→` `空格` `M` `F` 这些基础键默认不显示，
点「快捷键 ▾」展开全表。

### 鼠标

| 操作 | 作用 |
| --- | --- |
| 滚轮（画面上） | 上一条 / 下一条 |
| 点画面 | 暂停 / 继续 |
| 点主页封面 | 直接播这条 |
| 滚轮（主页封面墙） | 上下滚动 |

### 窗口

原生窗口：拖动、双击标题栏、贴边分屏、`Win` + 方向键都正常。

最大化铺满**工作区**（不盖任务栏），`F` 才是真全屏。

程序按 PerMonitorV2 声明 DPI 感知，拖到 125% / 150% 缩放的屏幕上会重新排版，
不会被系统拉伸成糊图。

`Esc` 是「退一层」：全屏时退全屏，在作者主页时回推荐流并切回详情页。

### 启动不用再等

退出时会把当前这批推荐和位置存下来，下次打开在 48 小时内就直接接着播，
不用重新拉推荐——只发一个 1KB 的 Range 请求确认播放地址还有效。
预取过的视频开头也存在硬盘上（`data/prefetch`），
上限 120MB / 120 条、7 天过期，启动时自动整理。

### 右侧面板

**详情页**显示：

- 作者、文案、点赞 / 评论 / 分享数
- 背景音乐
- 视频技术参数：**分辨率、帧率、码率**

技术参数来自播放器的实时数据，不是接口返回值——所以它反映的是你**实际在播的那一路流**。

**评论页**（按 `Tab` 或点「评论」）：

- 显示热门评论，往下滚自动加载更多
- 每条带昵称、IP 属地、时间、点赞数
- **带「展开 N 条回复」的评论，点一下就在下面展开回复**，再点「收起回复」收起来

### 推荐 / 关注 / 喜欢 / 收藏

**标题栏左上角**有四个按钮：推荐、关注、喜欢、收藏。点一下切过去，当前那个会变红。

- **推荐**：默认的信息流
- **关注**：关注的人发的视频，按作者去重（短剧号一天发几十条，不去重的话一页全是同一个人）
- **喜欢**：自己点过赞的视频。右侧会切成**封面墙**（三列缩略图，和作者主页一样），点哪个播哪个，播到快到底会自动加载下一页
- **收藏**：默认收藏夹（「我的收藏」）里的视频，同样是封面墙，同样自动翻页

喜欢和收藏用封面墙而不是一条条划，是因为"翻自己的收藏"更适合先扫一眼再挑着看。
封面墙上会高亮当前正在播的那条。

三个都要登录才有内容。没登录时点会提示先去登录。

**在喜欢 / 收藏页里，「主页」Tab 显示的是"我的喜欢/收藏"封面墙，不是当前视频作者的主页。**
想看作者主页，按 `U`（默认绑定，可在 设置 → 快捷键 改）。按 `U` 会切到该作者的作品墙，
再按一次回推荐。

> 注意：这几个流都是临时的，不会存进「接着上次看」——下次启动还是从推荐流开始。

### 内容偏好：标签分组

设置 → 播放 → 「内容偏好（标签分组）」：

- 上面一排是分组按钮，点一下切过去
- 下面的框里一行写一个标签：直接写 = 只看这类，`-` 开头 = 屏蔽这类
- 「＋ 新建分组」「删除当前组」；组名在上面的框里直接改
- 改完立刻生效，去 设置 → 快捷键 给「切换标签分组」绑个键，主界面按一下就换一套

匹配是包含关系（写"短剧"能命中 `#热播短剧` `#AI短剧`），不区分大小写。

**标签来源**：详情页显示的是平台标签（抖音给的分级分类，如「美食 → 美食探店」），
但平台标签只有详情接口给，推荐流里没有。所以**过滤用的是作者标签**（覆盖率 84%）。
填规则时用两套里共有的词（`美食` `影视` `游戏`）最稳。

**一次拉多少条**：固定 10 条。过滤后不够 10 条会自动再拉几轮（最多 60 条）。
拉的是纯信息，不会下载视频。

### 看推荐倾向

设置 → 推荐倾向 → 选采样数量（20 / 40 / 60 / 100 条）→ 点「开始分析」。

它会拉一批推荐，**逐条读取平台标签**（抖音自己的三级分类，如「美食 → 美食探店 → 餐厅探店」），
告诉你平台此刻正在推给你什么：

- **主题分布**：游戏、影视、二次元、美食、随拍……直接用抖音的一级分类，按占比排
- **高频标签**：出现最多的话题
- **作者集中度**：这一批里谁刷屏了
- 鼠标停在某一行上，能看到该主题的代表标签

**数量怎么选**：平台标签只在详情接口里（推荐流一条都没有），每条要多花 0.6 秒。
20 条约 16 秒、40 条约 30 秒、60 条约 44 秒、100 条约 75 秒。数量越多结论越稳，
但 40 条通常已经够看了。

几点说明：

- 平台标签只在**详情接口**里，推荐流里一条都没有（实测 29 条全空），所以每条要多花 0.6 秒
- 拿不到平台标签的那几条会退回用作者标签，结论里会注明「按平台分类」还是「按作者标签」
- 它反映的是「服务端此刻推什么」，**不完全等于「你是什么人」**——推荐会随你看的内容漂移
- 占比的分母是**能归类的条数**，不是总条数（没标签的内容不参与，否则分布会被压扁）
- 平台运营标签（`#抖音精选计划` `#AI创作浪潮计划`）不计入主题，只在结论里提一句
- **未登录时结果偏"大众"**，登录后再分析才贴近你自己的兴趣

### 登录

设置 → 账号 → 扫码登录（或点右下角的「登录已过期」提示）。
按 `Ctrl+O` 打开设置 → 账号 → 扫码登录：

1. 弹出登录窗口，抖音的二维码会自动出现
2. 用抖音 App 扫码
3. 登录成功后窗口自动关闭
4. 推荐流会变成个性化内容，评论也能看全

登录状态会记住，下次打开不用重扫。要退出登录，在设置 → 账号里点「退出登录」。

**怎么判断登录是不是真的有效**：设置 → 账号里那行小字。它现在查的是
`user/profile/self` 这个接口——只有服务端真的认这份登录态，它才返回 0；
不认就明确回「用户未登录」。所以显示「可能已过期」就是真的要重扫了，
别信"有 Cookie 就算登录"（评论能看、主页能开都不代表登录有效，游客也能看）。

### 图集作品

图文作品会直接显示图片，**右上角有「2 / 4」这样的页码**。
`←` `→` 翻页，`↑` `↓` 切到下一个作品。

**推荐流里目前刷不到图集。** 2026-10-25 实测：登录态下连续拉 80 条
（`module/feed` + `tab/feed` 两个接口），`aweme_type` 全是 0（视频），
`images` 字段一条都没有。用户实际保存的现场数据 16 条也是 0 图集。
早期版本确实混入过图文，现在接口不给这个字段了。

看图集只有一条可靠的路：**按 `Tab` 切到「主页」**，从作者的封面墙里找
（比例不高，一个作者二十来条里可能就一条）。

从封面墙点一条作品开始播以后，刷到作者的其他视频也不怕：
**按 `Esc` 就回推荐流**，右侧同时切回「详情」页。
推荐流不会重新加载，位置还是你离开时那一条。

主页是**封面墙**：三列等宽，显示封面、时长、点赞数，当前正在播的那条有高亮边框。
只加载封面图，不会把作者所有视频都拉下来。

> 想看演示效果也可以用本地注入的假数据（需要项目内的 Python 环境，先 `. .\scripts\env.ps1`）：
> ```powershell
> python tools\probe\gen_demo_images.py
> cd src
> dotnet run --project DouyinDesktop.App -- --demo-image
> ```
> 图片生成在 `tmp\demo\`（不进版本库，需要时重跑脚本即可）。

## 四、数据存在哪

**全部在程序目录的 `data\` 下**（跟着 exe 走，整个文件夹可以拷到别的电脑用）：

| 位置 | 内容 | 能删吗 |
| --- | --- | --- |
| `data\session.json` | 登录凭据、设备标识 | 删了要重新扫码 |
| `data\settings.json` | 快捷键绑定 | 删了恢复默认 |
| `data\app-settings.json` | 播放设置（只看图集、弹幕外观） | 删了恢复默认 |
| `data\last-session.dat` | 上次看到哪（48 小时内有效） | 随时可删 |
| `data\api-templates.json` | 接口模板（评论用） | 删了下次自动重抓 |
| `data\prefetch\` | 预取过的视频开头（≤120MB） | 随时可删 |
| `data\danmaku\` | 弹幕字幕文件 | 随时可删 |
| `data\logs\` | 运行日志（按天分文件） | 随时可删 |
| `data\WebView2\` | 登录窗口的浏览器数据 | 删了要重新扫码 |

**遇到问题先看日志**：`data\logs\app-年月日.log`。

（如果程序放在 `Program Files` 这种只读位置，写不进去，数据会自动退回
`%LOCALAPPDATA%\DouyinDesktop`。）

## 五、常见问题

### 提示"找不到 mpv.exe"

```powershell
.\scripts\fetch-mpv.ps1
```

或者设置环境变量 `DY_MPV` 指向你的 mpv.exe。

### 切换视频有时候要等一秒

正常。第一条视频没有"上一条"可以提前下载，只能等网络。
之后每条的开头 1MB 会在你看当前这条时提前下好，所以切换是瞬间的。

如果连续快速切换，预取跟不上，会退回走网络（约 0.6–1.4 秒）。

### 画面卡住 / 黑屏

1. 翻到下一条（翻到列表快见底会自动补一批；想立刻换一批，去 设置 → 快捷键 给「换一批推荐」绑个键）
2. 还不行就重启程序
3. 看日志里有没有「加载失败」

### 评论加载不出来

评论区需要登录态。`Ctrl+O` → 账号 → 扫码登录后再试。
如果登录了还是空的，可能是触发了风控，等几分钟。

### 登录失效了

抖音的登录 Cookie 有有效期（通常几个月）。
失效后点右下角的「登录已过期」提示，或 `Ctrl+O` → 账号 → 重新登录。

### 全屏后右侧信息没了

全屏就是把画面铺满，信息面板会隐藏。按 `Esc` 或 `F` 退出全屏就回来了。

### 输入法弹出来挡住按键

主窗口已经禁用了输入法，不会出现这个情况。
如果还有问题，检查是不是别的程序抢了焦点。

## 六、卸载 / 清理

这个程序不写注册表、不装服务、不改系统设置。

```powershell
# 1. 删程序文件夹（exe + assets\mpv + data\）——数据就在里面，一起没了
# 2. 如果程序曾放在只读位置、数据退回过去了 LOCALAPPDATA，再删这一份
Remove-Item -Recurse "$env:LOCALAPPDATA\DouyinDesktop" -ErrorAction SilentlyContinue

# 3. 如果不再需要 .NET 10 SDK（通用工具，其他 C# 项目可能还要用）
Remove-Item -Recurse "$env:USERPROFILE\.dotnet"
```
