# 使用手册

> 面向使用者，不讲原理。想了解实现看 `接口笔记.md`，想了解为什么这么设计看 `PLAN.md`。

---

## 一、这是什么

一个 Windows 上刷抖音的桌面程序。

它**不打开抖音网页**，而是直接走接口拿视频、用 mpv 播放。所以：

- 没有网页加载的等待，切换视频通常在 100 毫秒以内
- 没有广告、没有推荐位、没有埋点
- 内存占用约 400 MB（主程序 + 播放器）

支持：推荐流、扫码登录、评论区、图集作品、全屏、键盘快捷键。

## 二、第一次运行

### 前置条件

| 需要什么 | 怎么确认 | 没有怎么办 |
| --- | --- | --- |
| .NET 10 运行时 | 项目里 `scripts/env.ps1` 会检查 | 跑 `scripts\setup.ps1` |
| mpv 播放器 | `assets\mpv\mpv.exe` 存在 | 跑 `scripts\fetch-mpv.ps1` |

### 启动

在项目根目录打开 **PowerShell**：

```powershell
. .\scripts\env.ps1
cd src
dotnet run --project DouyinDesktop.App
```

> 前面那个点号不能少。它表示"在当前窗口执行"，少了它环境变量不会留下。

**为什么不建议双击 exe**：.NET 10 装在用户目录、没进系统 PATH，直接双击会弹
"You must install or update .NET"。如果确实想双击，把 `C:\Users\<你的用户名>\.dotnet`
加进系统环境变量 `DOTNET_ROOT` 就行。

## 三、怎么用

### 键盘

| 按键 | 作用 |
| --- | --- |
| `↑` / `W` | 上一条 |
| `↓` / `S` | 下一条 |
| `←` / `A` | 快退 5 秒（图集时：上一张） |
| `→` / `D` | 快进 5 秒（图集时：下一张） |
| `空格` | 暂停 / 继续 |
| `M` | 静音 |
| `F` | 全屏（`Esc` 退出） |
| `Tab` | 切换「详情 / 评论」 |
| `R` | 换一批推荐 |
| `L` | 登录（扫码） |

鼠标滚轮也能切换上一条 / 下一条。

### 右侧面板

**详情页**显示：

- 作者、文案、点赞 / 评论 / 分享数
- 背景音乐
- 视频技术参数：**分辨率、帧率、码率、编码格式、解码方式**

技术参数来自播放器的实时数据，不是接口返回值——所以它反映的是你**实际在播的那一路流**。
「解码」显示 `d3d11va` 之类的名字表示在用显卡硬解，显示「软解」表示在用 CPU。

**评论页**（按 `Tab` 或点「评论」）：

- 显示热门评论，往下滚自动加载更多
- 每条带昵称、IP 属地、时间、点赞数

### 图集作品

抖音的图文作品会直接显示图片，底部有「2 / 5」这样的页码。
`←` `→` 翻页，`↑` `↓` 切到下一个作品。

> 注意：**当前的推荐流接口只返回视频，不返回图集**（实测扫 48 条，`images` 字段一条都没有）。
> 图集功能已经实现并验证过，等接入搜索或主页接口后自然生效。
>
> 想现在看效果：
> ```powershell
> python tools\probe\gen_demo_images.py      # 生成 3 张演示图
> cd src
> dotnet run --project DouyinDesktop.App -- --demo-image
> ```
> 这条命令会在列表最前面插一条本地图集，`←` `→` 可以翻页。

### 登录

按 `L` 或点标题栏的「登录」：

1. 弹出登录窗口，抖音的二维码会自动出现
2. 用抖音 App 扫码
3. 登录成功后窗口自动关闭，标题栏变成「已登录」
4. 推荐流会变成个性化内容，评论也能看全

登录状态会记住，下次打开不用重扫。

## 四、数据存在哪

| 位置 | 内容 | 能删吗 |
| --- | --- | --- |
| `%LOCALAPPDATA%\DouyinDesktop\session.json` | 登录凭据、设备标识 | 删了要重新扫码 |
| `%LOCALAPPDATA%\DouyinDesktop\logs\` | 运行日志（按天分文件） | 随时可删 |
| `%LOCALAPPDATA%\DouyinDesktop\WebView2\` | 登录窗口的浏览器数据 | 删了要重新扫码 |

**遇到问题先看日志**：`%LOCALAPPDATA%\DouyinDesktop\logs\app-年月日.log`。

## 五、常见问题

### 提示"找不到 mpv.exe"

```powershell
.\scripts\fetch-mpv.ps1
```

或者设置环境变量 `DY_MPV` 指向你的 mpv.exe。

### 切换视频有时候要等一秒

正常。第一条视频没有"上一条"可以提前下载，只能等网络。
之后每条的开头 1MB 会在你看当前这条时提前下好，所以切换是瞬间的。

如果连续快速切换，预取跟不上，会退回走网络（约 0.6–1.4 秒）。

### 画面卡住 / 黑屏

1. 按 `R` 换一批
2. 还不行就重启程序
3. 看日志里有没有「加载失败」

### 评论加载不出来

评论区需要登录态。按 `L` 扫码登录后再试。
如果登录了还是空的，可能是触发了风控，等几分钟。

### 登录失效了

抖音的登录 Cookie 有有效期（通常几个月）。失效后按 `L` 重新扫码即可。

### 全屏后右侧信息没了

全屏就是把画面铺满，信息面板会隐藏。按 `Esc` 或 `F` 退出全屏就回来了。

### 输入法弹出来挡住按键

主窗口已经禁用了输入法，不会出现这个情况。
如果还有问题，检查是不是别的程序抢了焦点。

## 六、卸载 / 清理

这个程序不写注册表、不装服务、不改系统设置。

```powershell
# 1. 删项目文件夹（含源码和 mpv）
# 2. 删用户数据（登录凭据、日志、浏览器缓存）
Remove-Item -Recurse "$env:LOCALAPPDATA\DouyinDesktop"

# 3. 如果不再需要 .NET 10 SDK（通用工具，其他 C# 项目可能还要用）
Remove-Item -Recurse "$env:USERPROFILE\.dotnet"
```
