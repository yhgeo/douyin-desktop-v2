> 尺寸是 2026-10-21 的实测值。

## 一、项目里的东西（跟着文件夹走）

### `env\python` —— Python 虚拟环境

**是什么**：一个装了特定依赖的独立 Python 副本。

**为什么需要**：项目里有两个 Python 脚本（`tools/probe/` 下）用来验证抖音接口有没有变。
它们需要 `curl_cffi` 这类第三方包。如果直接装在系统 Python 里，可能和你别的项目打架，
所以单独开一个箱子。

**为什么不影响你**：它不注册到系统，不修改任何环境变量，不装到 `C:\Python`。
只有你手动运行 `env\python\Scripts\python.exe` 时才会用到它。

**怎么删**：直接删 `env\python` 整个文件夹。
**怎么恢复**：`scripts\setup.ps1` 会自动重建。

> 补充一句：这个项目最终交付的是 C# 程序，**跑起来完全不需要 Python**。
> Python 只是我开发时用来验证接口的工具，属于"脚手架"，将来可以拆掉。

### `vendor` —— 参考仓库

**是什么**：两个别人的开源项目，只读，不参与编译。

- `DouYin_Spider`：签名算法的参考实现（我们要移植的核心）
- `douyin-desktop-v1`：你的第一版 Electron 应用（看它踩过哪些坑）

**怎么删**：直接删。`scripts\setup.ps1` 会重新克隆。
**注意**：删了之后我就没法对照签名算法了，移植工作会停。

### `assets\mpv` —— 播放器

**是什么**：mpv 播放器，一个独立的 exe。视频解码、硬件加速、音画同步全靠它。

**为什么用它**：自己写解码器要几个月，而且做不好。mpv 是成熟的开源播放器，
我们只是"遥控"它——告诉它播哪个地址、什么时候暂停、画面贴在哪。

**为什么单独放一个进程**：万一它崩了，主程序不受影响，自动重启就行。

**已经就位**：`assets\mpv` 里是 `mpv.exe`（约 115 MB）+ `mpv.com` + `d3dcompiler_43.dll`，
合计 120 MB。要重新下载跑 `scripts\fetch-mpv.ps1`。

## 二、项目外面的东西（全局工具）

### `C:\Users\tea\.dotnet` —— .NET SDK

**是什么**：微软的 C# 编译器和运行环境，784 MB。

**为什么放在项目外面**：它是**通用工具**，和你以后任何 C# 项目都能共用。
如果塞进项目文件夹，你每做一个 C# 项目就要多存 784 MB，不划算。

**为什么不装到 `Program Files`**：装到系统目录需要管理员权限（会弹 UAC）。
这个版本装在用户目录，不需要管理员，删起来也干净（直接删文件夹）。

**怎么用**：正常情况下系统找不到它。项目里的 `scripts\env.ps1` 会临时把它加进 PATH，
只对当前那个 PowerShell 窗口有效，关掉就恢复原样。

**怎么删**：删 `C:\Users\tea\.dotnet` 文件夹，再把用户环境变量里可能存在的
`DOTNET_ROOT` 删掉（如果有的话）。

**顺带清理**：`C:\Users\tea\dotnet-install.ps1`（76 KB）是安装脚本，装完就没用了，可以删。

## 四、怎么确认环境是好的

```powershell
. .\scripts\env.ps1
dotnet --version          # 应输出 10.0.402
python --version          # 应输出 Python 3.13.x（项目内的那个）
```

如果 `dotnet --version` 报错，说明 `env.ps1` 没生效——注意前面那个点号不能少
（`. .\scripts\env.ps1`，点号表示"在当前窗口执行"，少了它设置不会留下）。
