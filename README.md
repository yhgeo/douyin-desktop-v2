# 抖音桌面版

原生接口 + mpv 播放，**不加载网页**的 Windows 抖音客户端。

目标只有一个：刷视频比网页版快，没有广告和埋点。

> 仅供个人学习使用。不内置任何绕过付费/版权的内容，也不分发抓取到的视频。

---

## 为什么不用网页版

网页版打开一个视频要几秒，实测网络只占 0.2 秒——剩下全花在 React 挂载、埋点 SDK、播放器初始化、广告位上。

原生客户端里这些东西**一个都不存在**：直接拿接口数据，交给 mpv 解码，切视频平均 **100 毫秒**。

## 下载安装

到 [**Releases**](https://github.com/yhgeo/douyin-desktop-v2/releases/latest) 下载两个文件：

| 文件 | 内容 | 大小 |
| --- | --- | --- |
| `douyin-desktop-v2-core.zip` | 主程序（自带 .NET 运行时，不用装 SDK） | 54 MB |
| `mpv-win64.zip` | 播放器，**只需下载一次** | 46 MB |

**安装三步：**

1. 解压 `douyin-desktop-v2-core.zip` → 得到 `DouyinDesktop` 文件夹
2. 解压 `mpv-win64.zip`，把里面的 `assets` 文件夹拖进 `DouyinDesktop`
   → 合并后路径是 `DouyinDesktop\assets\mpv\mpv.exe`
3. 双击 `DouyinDesktop.exe`

> 第一次运行 Windows 可能提示「Windows 已保护你的电脑」——点「更多信息」→「仍要运行」。
> 这是因为程序没有购买代码签名证书，不是有问题。

**以后更新**：只下载新的 `core` 包，覆盖 `DouyinDesktop.exe` 就行。
`mpv` 不用重新下载，`data`（登录态、设置）也不会被动。

## 使用教程

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` / `W` | 上一条 |
| `↓` / `S` | 下一条 |
| `←` / `A` | 快退 5 秒（图集时上一张） |
| `→` / `D` | 快进 5 秒（图集时下一张） |
| `空格` | 暂停 / 继续 |
| `M` | 静音 |
| `F` | 全屏（`Esc` 退出） |
| `Tab` | 循环切换「详情 → 评论 → 主页」 |
| `G` | 切换「关注 / 推荐」 |
| `X` | 点赞 / 取消点赞（需登录） |
| `B` | 在浏览器中打开当前作品 |
| `Esc` | 退一层：全屏→退全屏；作者主页→回推荐 |
| `Ctrl+O` | 打开设置 |

快捷键可以在 **设置 → 快捷键** 里改，也能点「清除」把某一项取消掉。
详情页只列不常用的键，`↑↓←→` `空格` `M` `F` 这些默认不显示，点「快捷键 ▾」展开全表。

**作者主页、换一批、登录默认不绑键**——都不是高频操作，绑着反而容易误触
（回推荐用 `Esc`，换一批翻到快见底会自动补，登录在设置 → 账号里有入口）。
要用的自己去设置里加。
### 鼠标

| 操作 | 作用 |
| --- | --- |
| 滚轮（画面上） | 上一条 / 下一条 |
| 点画面 | 暂停 / 继续 |
| 点主页封面 | 直接播这条 |
| 滚轮（主页封面墙） | 上下滚动 |

### 窗口

这是个原生窗口，拖动、双击标题栏、贴边分屏、`Win` + 方向键都正常。

最大化 = 铺满**工作区**（不盖任务栏）；`F` 才是真全屏（连任务栏一起盖）。

程序按 PerMonitorV2 声明了 DPI 感知：拖到 125% / 150% 缩放的另一块屏幕上会
重新排版，不会被系统拉伸成一张糊图。

`Esc` 是「退一层」：全屏 → 退全屏；作者主页 → 回推荐流；其它 Tab → 回详情页。

### 启动不用再等

关掉程序时会把**当前这批推荐 + 看到第几条**存下来（`data/last-session.dat`）。

下次打开如果还在 48 小时内，直接接着上次那条播——**不用重新拉推荐**，
只发一个 1KB 的 Range 请求确认播放地址还没过期，比拉一批推荐快得多。

上次预取过的视频开头也留在硬盘上（`data/prefetch`），下次直接命中，秒开。

不会无限堆积：预取缓存最多 120MB / 120 条、超过 7 天自动删、每次启动整理一次。
删掉 `data/prefetch` 只是下次重新预取，不影响别的。

### 登录

`Ctrl+O` → 账号 → 扫码登录（或点右下角的「登录已过期」提示）。

弹出登录窗口后抖音的二维码会自动出现，用手机扫一下，成功窗口自动关闭。
登录后推荐流是个性化的，评论也能看全。

登录状态会记住，下次打开不用重扫。

### 图集

刷推荐时能遇到图文作品：直接显示图片，**右上角有「1 / 4」这样的页码**，
`←` `→` 翻页，`↑` `↓` 切下一个作品。

图集的详情页显示的是**图片张数和尺寸**，不是视频的分辨率/帧率。

也可以按 `Tab` 切到「主页」看作者的全部作品——那里图集更集中。
（想用快捷键进主页，去 设置 → 快捷键 给「作者主页」绑一个键。）

从封面墙点一条作品开始播以后，刷到作者的其他视频也不怕：
**按 `Esc` 就回推荐流，并且右侧自动切回「详情」页**，
推荐流的位置还是你离开时那一条（不会重新加载）。

### 弹幕

设置 → 播放 → 「显示弹幕」（默认关）。

只有创作者发布时开启了弹幕的作品才有，不是每条都有。白字黑边、从右往左滚，6 条轨道自动避让。

渲染方式说明：视频是独立 Win32 子窗口（HwndHost），按 airspace 规则界面层画的任何东西
都会被它盖住，所以弹幕交给播放器渲染成**字幕轨**——代价是外观只能是字幕样式，
好处是暂停、拖动、快进全都自动同步。

### 评论区

按 `Tab` 切到评论页，往下滚自动加载更多。

带「展开 N 条回复」的评论，点一下就在下面展开，再点「收起回复」收起来。

### 技术参数

右侧详情页显示分辨率、帧率、码率——这些是**播放器实时上报的数据**，
不是接口返回值，所以反映的是你实际在播的那一路流。

图集显示的是图片张数和尺寸，不是视频参数。

### 关注页

按 `G` 在「关注」和「推荐」之间切换。**需要登录**，游客态下关注流是空的。

### IP 属地

**评论区的 IP 属地是有的**（`ip_label`），每条评论下面都会显示，比如「广东」。

**作品本身的 IP 属地拿不到**——这是实测结论，不是没做：

- 列表接口（`module/feed`、`tab/feed`、`aweme/post`）里 `ip_label` 字段根本不存在，`region` 恒为空
- 作品详情接口（`aweme/detail`）也一样，把 109KB 的完整响应存下来 grep 过，没有
- 网页版本身也不显示这个，所以不是签名或参数的问题

登录态下也一样。所以视频详情页那行只显示「发布时间」，不假装有属地。

### 只看图集（实验性，目前失效）

设置 → 播放 → 只看图集。开启后加载推荐流时会丢掉视频，只留图文作品。

**实测结论（2026-10-25）**：登录态下连续拉 80 条（`module/feed` + `tab/feed`），
`aweme_type` 全是 0（视频），`images` 字段一条都没有。用户实际保存的现场数据 16 条也是 0。

所以这个开关**现在大概率拉不到内容**，开了只会连发 6 次请求然后提示"没找到"。
代码保留着是因为接口随时可能变回来。

**要看图集请按 `Tab` 切到「主页」**，从作者的封面墙里找——那条接口（`aweme/post`）一直有图集。

## 数据存在哪

全部在程序目录的 `data\` 下，不写注册表、不装服务：

```
DouyinDesktop\
├─ DouyinDesktop.exe
├─ assets\mpv\           播放器
└─ data\
   ├─ session.json       登录凭据 + 游客设备标识（ttwid / s_v_web_id / msToken）
   ├─ settings.json      快捷键绑定
   ├─ app-settings.json  播放设置（只看图集、弹幕外观等）
   ├─ last-session.dat   上次看到哪（GZip 过的推荐列表 + 位置，48 小时内有效）
   ├─ api-templates.json 接口 URL 模板（评论用，缺失时自动抓一次）
   ├─ webid.txt          浏览器真实 webid（强校验接口用）
   ├─ webid-app.txt      本机稳定 webid（推荐流用，换掉会冷启动）
   ├─ prefetch\          预取过的视频开头（最多 120MB / 120 条，7 天过期）
   ├─ danmaku\           生成的弹幕字幕文件
   ├─ logs\              运行日志（含 mpv 日志）
   └─ WebView2\          登录窗口的浏览器数据
```

**整个文件夹可以直接拷到别的电脑用**，登录态和设置都跟着走。
想清空所有痕迹，删掉 `data` 文件夹即可（`prefetch` / `danmaku` 是纯缓存，单独删也行）。

（如果放在 Program Files 这类只读位置，数据会自动退回 `%LOCALAPPDATA%\DouyinDesktop`）

## 常见问题

**没画面 / 黑屏**
检查 `assets\mpv\mpv.exe` 是否存在。这个包要单独下载，不在 core 包里。

**切换视频有时候要等一秒**
第一条视频没有"上一条"可以提前下载，只能等网络。之后每条的开头 1MB 会在你看当前这条时提前下好，所以切换是瞬间的。

**评论加载不出来**
评论区需要登录态。`Ctrl+O` → 账号 → 扫码登录后再试。

**登录失效了**
抖音的 Cookie 有有效期（通常几个月）。失效后点右下角提示，或 `Ctrl+O` → 账号 → 重新登录。

**全屏后右侧信息没了**
全屏就是把画面铺满，信息面板会隐藏。按 `Esc` 或 `F` 退出全屏就回来了。

## 从源码运行

需要 .NET 10 SDK。

```powershell
# 1. 激活环境（把 dotnet 加进 PATH，只在当前窗口有效）
. .\scripts\env.ps1

# 2. 运行
cd src
dotnet run --project DouyinDesktop.App
```

播放器需要单独下载：

```powershell
.\scripts\fetch-mpv.ps1
```

### 发布到本机安装目录

```powershell
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1
```

publish 出单文件 exe，然后只覆盖安装目录的 `DouyinDesktop.exe` / `使用说明.txt` / `diagnose.bat`，
**不动** `assets\`（mpv，115MB）和 `data\`（登录态、设置、缓存）。

程序正在运行的话 exe 会被占用，脚本会直接报错退出——先关掉程序再跑。

### 改完代码先自检

```powershell
powershell -ExecutionPolicy Bypass -File scripts\check.ps1
```

编译 → 签名测试 → 偷懒代码扫描（slopwatch，只报相对基线**新增**的空 catch /
禁用测试 / 抑制警告）→ 离线探针。全程不联网、不弹窗。

加 `-Full` 会额外跑联网探针（凭据 → 推荐流 → 播放地址）。
