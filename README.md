# 抖音桌面版

原生接口 + mpv 播放，**不加载网页**的 Windows 抖音客户端。

目标只有一个：刷视频比网页版快，没有广告和埋点。切换视频中位 **197ms**。

> 仅供个人学习使用。不内置任何绕过付费/版权的内容，也不分发抓取到的视频。

---

## 为什么不用网页版

网页版打开一个视频要几秒，实测网络只占 0.2 秒——剩下全花在 React 挂载、埋点 SDK、播放器初始化、广告位上。

原生客户端里这些东西**一个都不存在**：直接拿接口数据，交给 mpv 解码。

## 下载安装

到 [**Releases**](https://github.com/yhgeo/douyin-desktop-v2/releases/latest) 下载两个文件：

| 文件 | 内容 | 大小 |
| --- | --- | --- |
| `douyin-desktop-v2-core.zip` | 主程序（自带 .NET 运行时，不用装 SDK） | 57 MB |
| `mpv-win64.zip` | 播放器，**只需下载一次** | 46 MB |

**安装三步：**

1. 解压 `douyin-desktop-v2-core.zip` → 得到 `DouyinDesktop` 文件夹
2. 解压 `mpv-win64.zip`，把里面的 `assets` 文件夹拖进 `DouyinDesktop`
   → 合并后路径是 `DouyinDesktop\assets\mpv\mpv.exe`
3. 双击 `DouyinDesktop.exe`

> 第一次运行 Windows 可能提示「Windows 已保护你的电脑」——点「更多信息」→「仍要运行」。
> 这是因为程序没有购买代码签名证书，不是有问题。

**以后更新**：只下载新的 `core` 包，覆盖 `DouyinDesktop.exe` 就行。
`mpv` 不用重新下载，`data`（登录态、设置）也不会被动。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` / `W` | 上一条 |
| `↓` / `S` | 下一条 |
| `←` / `A` | 快退 5 秒（图集时上一张） |
| `→` / `D` | 快进 5 秒（图集时下一张） |
| `空格` | 暂停 / 继续 |
| `M` | 静音 |
| `F` | 全屏（`Esc` 退出） |
| `Tab` | 循环切换「详情 → 评论 → 主页」 |
| `/` | 搜索视频 |
| `G` | 切换「关注 / 推荐」 |
| `U` | 看当前作者主页 / 回推荐 |
| `X` | 点赞 / 取消点赞（需登录） |
| `B` | 在浏览器中打开当前作品 |
| `Esc` | 退一层：全屏→退全屏；作者主页→**回进来时那一页** |
| `Ctrl+O` | 打开设置 |

详情页只列不常用的键，`↑↓←→` `空格` `M` `F` 默认折叠，点「快捷键 ▾」展开全表。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 推荐流 | 原生接口直取，切视频 197ms，无广告无埋点 |
| 搜索 | 按 `/` 输入关键词，结果作为独立的流；`Esc` 回推荐，位置还在 |
| 关注 / 喜欢 / 收藏 | 标题栏左上角切换。喜欢和收藏是**封面墙**（三列缩略图），点哪个播哪个，自动翻页 |
| 作者主页 | 按 `U` 看当前作者的全部作品，封面墙选片 |
| 评论区 | 自动加载更多，回复可展开 |
| 图集 | 推荐流和作者主页都能刷到，`←` `→` 翻页 |
| 弹幕 | 创作者开了才有，播放器渲染成字幕轨（外观受限但同步完美） |
| 标签分组 | 自定义「只看 / 屏蔽」规则，按话题标签过滤推荐流 |
| 推荐倾向 | 设置里分析平台正在推什么：拉 20–100 条，逐条读**平台标签**（抖音三级分类） |
| 备份收藏 | 导出 JSON / CSV / 离线卡片墙。只存作品 ID 和视频 ID，几百 KB，不下载视频 |
| 接着上次看 | 关掉再开，接着上次那条播，预取过的开头还在硬盘上 |
| 网页兜底 | 按 `B` 在浏览器里打开当前作品 |

**登录**：`Ctrl+O` → 账号 → 扫码。登录后推荐个性化、评论看全、喜欢/收藏/关注才有内容。
设置页那行小字显示的是**真实**登录状态（查 `user/profile/self`），显示「可能已过期」就是真要重扫。

详细操作（每个功能怎么用、踩坑说明）见 [使用手册](docs/使用手册.md)。

## 数据存在哪

全部在程序目录的 `data\` 下，跟着 exe 走，整个文件夹可以拷到别的电脑用。

| 位置 | 内容 | 能删吗 |
| --- | --- | --- |
| `data\session.json` | 登录凭据、设备标识 | 删了要重新扫码 |
| `data\settings.json` / `app-settings.json` | 快捷键、播放设置 | 删了恢复默认 |
| `data\last-session.dat` | 上次看到哪（48 小时内有效） | 随时可删 |
| `data\prefetch\` | 预取过的视频开头（≤120MB） | 随时可删 |
| `data\logs\` | 运行日志，**遇到问题先看这里** | 随时可删 |
| `data\WebView2\` | 登录窗口的浏览器数据 | 删了要重新扫码 |

程序放在 `Program Files` 这种只读位置时，数据会自动退回 `%LOCALAPPDATA%\DouyinDesktop`。

完整清单（含弹幕、接口模板等）见 [使用手册 · 数据存在哪](docs/使用手册.md#四数据存在哪)。

## 常见问题

**切换视频有时候要等一秒** —— 正常。第一条没有"上一条"可以预取，只能等网络；之后每条开头 1MB 都提前下好了。

**画面卡住 / 黑屏** —— 先翻下一条（快见底会自动补），还不行重启程序，再看日志里有没有「加载失败」。

**评论加载不出来** —— 评论区需要登录；登录了还是空可能是触发风控，等几分钟。

**找不到 mpv.exe** —— 没把 `assets` 拖进程序目录，或者用 `scripts\fetch-mpv.ps1` 重新下载。

**全屏后右侧信息没了** —— 全屏就是铺满画面，按 `Esc` 或 `F` 退出就回来。

更多见 [使用手册 · 常见问题](docs/使用手册.md#五常见问题)。

## 从源码跑

需要 .NET 10 SDK（`scripts\setup.ps1` 会自动装到 `%USERPROFILE%\.dotnet`）。

```powershell
. .\scripts\env.ps1            # 激活环境（只影响当前窗口）
.\scripts\setup.ps1            # 首次：装 SDK + 建 Python 环境
.\scripts\fetch-mpv.ps1        # 首次：下载 mpv 到 assets\

cd src
dotnet run --project DouyinDesktop.App
```

| 命令 | 作用 |
| --- | --- |
| `scripts\check.ps1` | 编译 + 测试 + 懒代码扫描 + 离线探针（不联网、不弹窗） |
| `scripts\deploy.ps1` | 发布并覆盖到 `D:\Douyin_Desktop_2.0` |
| `dotnet run --project src/DouyinDesktop.Probe` | 数据层探针，几十个诊断子命令 |

项目结构见 [目录结构](docs/目录结构.md)。
