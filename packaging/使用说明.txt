抖音桌面版 —— 使用说明
================================

【安装（第一次）】
下载两个压缩包：

  1. douyin-desktop-v2-core.zip   ← 主程序
  2. mpv-win64.zip                ← 播放器（只需下一次）

步骤：
  1. 解压 douyin-desktop-v2-core.zip，得到 DouyinDesktop 文件夹
  2. 解压 mpv-win64.zip，把里面的 assets 文件夹拖进 DouyinDesktop
     合并后路径应该是：DouyinDesktop\assets\mpv\mpv.exe
  3. 双击 DouyinDesktop.exe

第一次运行 Windows 可能提示"Windows 已保护你的电脑"：
点「更多信息」→「仍要运行」即可。这是因为程序没有购买代码签名证书，
不代表有问题。源码在 https://github.com/yhgeo/douyin-desktop-v2

【更新（以后）】
只下载新的 douyin-desktop-v2-core.zip，把里面的 DouyinDesktop.exe
覆盖旧的就行。mpv 不用重新下载，data 文件夹也不会被覆盖。

【窗口】
最大化 = 铺满工作区，不会盖住任务栏。
F = 全屏（连任务栏一起盖住），Esc 退出。

Esc 是「退一层」：
  全屏时        -> 退出全屏
  在作者主页时  -> 回推荐流 + 右侧切回详情页

是原生窗口：拖动、双击标题栏、贴边分屏、Win+方向键都能用。
多显示器、125% / 150% 缩放也正常——程序按 PerMonitorV2 声明了 DPI 感知，
拖到另一块屏会重新排版，不会糊成一张拉伸的位图。
全屏铺满的是**当前窗口所在那块屏幕**，不是主屏。

【接着上次看】
关掉程序时会把「当前这批推荐 + 看到第几条」存下来。
下次打开如果还在 6 小时内，直接接着上次那条播，不用重新拉推荐。

地址放太久会失效，所以超过 6 小时的现场会直接拉一批新的——
宁可多等一次推荐，也不让你先看一秒黑屏再跳。

上次预取过的视频开头会留在硬盘上（data\prefetch），下次直接命中，秒开。

不会无限堆积：
  · 预取缓存最多 120MB / 120 条
  · 超过 7 天的自动删
  · 启动时在后台整理，不会卡住窗口
删掉 data\prefetch 文件夹也没事，只是下次重新预取。

【鼠标】
  点视频画面      暂停 / 继续（等同空格）
  主页封面墙滚轮  上下滚动
  点主页封面      直接播这条

【快捷键】
  ↑ / W          上一条
  ↓ / S          下一条
  ← / A          快退 5 秒（图集时上一张）
  → / D          快进 5 秒（图集时下一张）
  空格           暂停 / 继续
  M              静音
  F              全屏（Esc 退出）
  Tab            循环切换「详情 → 评论 → 主页 → 详情」
  X              点赞 / 取消（需要登录）
  B              在浏览器中打开当前作品（看完整评论、点赞都在这边做）
  G              切换「关注 / 推荐」
  Esc            退一层（全屏→退全屏；作者主页→回推荐）
  Ctrl+O         设置

U（作者主页）、R（换一批）、L（登录）**默认不绑键**——
都不是高频操作，绑着反而容易误触。要用的去 设置 → 快捷键 里自己加。
登录入口在 设置 → 账号，或点右下角的「登录已过期」提示。

快捷键可以在 设置 → 快捷键 里改，也可以点「清除」取消某一项。
详情页只列「不常用」的键，↑↓←→ 空格 M F 这些基础键默认不显示，
点「快捷键 ▾」可以展开看全表。

【三个 Tab】
右侧面板顶部有「详情 / 评论 / 主页」：

  详情  作者、文案、统计、音乐、分辨率/帧率/码率、快捷键表
  评论  一级评论 + 内联展开回复，带 IP 属地
  主页  当前作者的封面墙（头像 + 所有作品封面，带时长和点赞数），
        点封面直接播这条。只加载封面图，不会把视频全下下来。

点了封面就进了「作者主页」流，之后上下切换都是这个作者的作品。
**想回推荐：按 Esc**，右侧会自动切回「详情」页，
推荐流不会重新加载，还是你离开时那一条。

【三个流互不影响】
右下角有个小徽章显示当前在哪个流：推荐 / 关注 / 作者主页。

推荐、关注、作者主页各自记住自己的列表和位置——切来切去不会丢数据，
切回来还是刚才那一条。

作者主页翻到最后一条就停住（不会偷偷补推荐进来）。

【关注页】
按 G 在「关注」和「推荐」之间切换。**需要登录**，游客态下关注流是空的。

【弹幕】
设置 → 播放 → 「显示弹幕」打开后才有（默认关）。

只有创作者发布时开启了弹幕的作品才有弹幕，不是每条都有。
弹幕是白字黑边、从右往左滚动，最多 10 条轨道自动避让。

两种渲染方式，在 设置 → 播放 里选：

  字幕轨（默认）  交给播放器渲染。最稳，时序跟着视频走，暂停/拖动全同步。
                  代价是受视频帧率限制，快速移动时略有跳动。
  浮层（实验性）  一个跟着视频区域走的透明小窗口，按显示器刷新率自己画。
                  更顺滑，但窗口层级相关的问题多，遇到异常就取消勾选。

外观也在 设置 → 播放 → 显示弹幕 里调（勾上之后下面的选项才能动）：

  显示区域    顶部 / 中间 / 底部 / 全屏
  字号        1% - 6%（占画面高度的比例）
  不透明度    10% - 100%
  描边        0% - 30%（占字号的比例，0 就是不描边）
  移动速度    4 - 20 秒（一条弹幕从进入到完全离开）

关掉设置窗口就生效。这些值同时存在 data\app-settings.json 里，
也可以直接改文件（改完重启程序）：

  "Danmaku": true
  "DanmakuArea": "top"             top / middle / bottom / full
  "DanmakuFontPercent": 3.2
  "DanmakuOpacity": 90
  "DanmakuOutlinePercent": 10
  "DanmakuSpeed": 10
  "DanmakuRenderer": "ass"         ass = 字幕轨（默认）/ overlay = 浮层

超出范围会被自动夹到区间内，写错了也不会崩。

两条经验：
· 描边别调到 0。白字没有描边就完全贴在画面上，看着像一层发虚的雾；
  10% - 20% 是最舒服的区间（描边跟着字号走，字号调小描边也会跟着细）。
· 不透明度低于 70% 时更要注意描边，半透明白字没边缘最糊。

【图集】
**推荐流里现在刷不到图集。** 2026-10-25 实测：登录态下连续拉 80 条，
作品类型全是视频，图片字段一条都没有。早期版本确实混入过，接口后来不给了。

看图集只有一条可靠的路：**按 Tab 切到「主页」**，从作者的封面墙里找
（比例不高，一个作者二十来条里可能就一条）。

刷到图文作品会直接显示图片，右上角有「1 / 4」这样的页码，← → 翻页。
图集详情页显示图片张数和尺寸，不是视频的分辨率/帧率。
图集会播放背景音乐。

设置 → 播放 里还有个「只看图集」开关，**目前基本拉不到东西**
（原因同上），留着是因为接口随时可能变回来。

【内容偏好：标签分组】
设置 → 播放 → 「内容偏好（标签分组）」：

  上面一排是分组按钮，点一下切过去
  下面的框里一行写一个标签：直接写 = 只看这类，- 开头 = 屏蔽这类
  「＋ 新建分组」「删除当前组」，组名在上面框里直接改

匹配是包含关系（写"短剧"能命中 #热播短剧），不区分大小写。

改完去 设置 → 快捷键 给「切换标签分组」绑个键，主界面按一下就换一套。

详情页显示的标签是抖音给的分级分类（如"美食 · 美食探店"），
但它只有详情接口给，所以过滤用的是作者自己加的标签。
填规则时用"美食""影视""游戏"这类共有的词最稳。

一次拉 10 条，过滤后不够会自动再拉几轮。不会下载视频。

【登录】
设置 → 账号 → 扫码登录（或点右下角的「登录已过期」提示）。

登录后：
  · 推荐流变成个性化的（按你的账号推）
  · 评论能看全
  · 关注页才有内容
  · 点赞能生效

登录状态会记住，下次打开不用重扫。程序每 10 分钟会从内置浏览器
同步一次 Cookie（只读、不加载页面），所以不用频繁重新扫码。
设置页会显示凭据的有效期还剩多少天。

【数据存在哪】
全部在程序文件夹下的 data 目录里，不写注册表、不装服务：

  data\session.json        登录凭据 + 设备标识
  data\settings.json       快捷键设置
  data\app-settings.json   播放设置（弹幕外观等）
  data\last-session.dat    上次看到哪了（接着上次看用）
  data\api-templates.json  接口模板（评论用，删了会自动重抓）
  data\webid.txt           浏览器真实设备号（主页/详情要用）
  data\webid-app.txt       本机设备号（游客态兜底）
  data\prefetch\           预取过的视频开头（最多 120MB，可随时删）
  data\danmaku\            生成的弹幕字幕文件（可随时删）
  data\logs\               运行日志（按天分文件）
  data\WebView2\           登录窗口的浏览器数据

**整个 DouyinDesktop 文件夹可以直接拷到别的电脑用**，登录态和设置都跟着走。
想清空所有痕迹，删掉 data 文件夹即可。

（如果程序放在 Program Files 这类只读位置，数据会自动退回
 %LOCALAPPDATA%\DouyinDesktop）

【关于体积】
主程序 60MB：自带 .NET 运行时，目标机器不用装 SDK。
播放器 115MB：mpv 内置全部音视频格式解码器（官方构建就是这个体积）。

【常见问题】
- 没画面：检查 assets\mpv\mpv.exe 是否存在
- 切视频卡顿：第一次启动没有预取，之后会越来越顺；
  连续快速切换时预取跟不上，会退回走网络
- 登录失效：点右下角提示，或 设置 → 账号 → 重新登录
- 关注页空白：需要登录
- 主页一直转圈：看 data\logs 里带 [主页] 的行，会打印状态码和完整地址
- 想抓推荐流诊断：DouyinDesktop.exe --diagnose
- 日志在哪：data\logs\app-年月日.log

【说明】
仅供个人学习使用。不内置任何绕过付费/版权的内容，也不分发抓取到的视频。
